# Claudeと壁打ちしてUbuntu Serverを立てた話

## Ubuntu Serverを導入した経緯

- [[HP ENVY x360 Convertible]]を2020年頃に購入して，講義や課題諸々に使用していた
- タブレットとしても使えるタイプのコンバーチブル
    - タッチペンも購入して，ノートに使おうと思ったが，あまり快適でなかったので，結局そんなに使わなかった
- パームレスト部分に天然のウォールナットを使っているのがお気に入りポイント
- いつの間にやら背面のネジが緩み始め，微妙に合わないドライバで苦戦しているうちにネジ穴が潰れてしまいました
- 合うネジを探してみたものの，手に入らなかったので，近しいもので仮止めしてる状態
- バッテリーもあまり持ちが良くなくなり，常に充電して使用
- 日常使用かつ持ち歩くにはだいぶ心もとなくなったので，昨年8月ごろにMacを購入してからは，ほぼ放置
- そんなある日，Google Photoの無料枠の容量逼迫のため，データ整理しているうちに，ENVYの存在を思い出し，ストレージとして活用できないか検討を始めた
- Ubuntuの導入，運用も前から興味があった
- Claudeと壁打ちして，Ubuntu Serverとして活用することを決めた

## 何を追加したか

### 基本的な設定

- Ubuntu Server 26.04 LTSを導入
- SSH接続設定
    - 自分もClaudeもアクセスできるように
- スリープ防止設定
    - 閉じるとスリープしてしまう
    - 場所を取らずに，ずっと起動しておきたかった
- 自己ホスト型のあれこれを導入
- 以下，諸々細かい設定，トラブルは割愛して導入したものの紹介

### Docker

- 以降のシステムのすべてを一括管理
- サービスごとに`~/docker/<サービス名>/`以下にディレクトリを切り，それぞれ独立した`compose.yml`で管理
- 各コンテナに`restart: unless-stopped`を設定し，再起動やクラッシュ後も自動で立ち上がるように

### Tailscale

- VPNサービスの一つ
- GoogleやGitHubのアカウントでログインできる
- 個人利用の範囲なら無料で使える
- 外部公開無しで自宅サーバーの公開ができる
- 以降のシステムにも関わる
- 対象ユーザが自分だけのサービスはだいたいこのVPN環境内で利用できるように

### Immich

- 自分でホストできる写真アルバム
- Google Photoから写真や動画の移行
- スマホやMacから閲覧・追加ができるように
- Background BackupをONにした
- スマホではバッテリーの制限無しにして，自動バックアップが常に動くようにした．
- あと，常時接続VPNをONにして常にTailscaleに接続するように設定した

### AdGuard Home

- DNSベースの広告ブロック
- 衝突するIPを避けてLAN IPとTailscale IPにだけバインドした
- DNS適用はTailscale Global nameserversを使用した
- Tailscaleに接続されている全端末に適用される
    - Override DNS serversをONにしている
- IPが固定されているので再設定が必要無い
- 一箇所で設定が完結するが，サーバーが止まると全端末で名前解決不能になってしまうリスクはある
    - 自宅に常時起動で置く運用を前提にしているので，採用した
    - 他には，各端末のWi-Fi設定でDNSを手動指定する選択肢も検討していた
- AdGuard DNS filter（デフォルトでON）
- OISD Blocklist Small
- セキュリティ系フィルタ（フィッシング/マルウェア）

### Vaultwarden

- Bitwarden互換の自己ホスト型パスワードマネージャー
- GoogleやCometのパスワードマネージャーから設定を移行した
- Tailscale ServeでLet's Encryptの正式証明書を取得し，自前ドメイン無しでHTTPS化した
    - ブラウザ拡張やモバイルアプリがHTTPSを必須とするため
    - リバースプロキシやドメインが不要
    - 以降のサービスでも同じ方法でHTTPS化できる
- バックアップはSQLite3で日次実行，Macへの遠隔コピーを取って対応
    - WALモードで動かしているので，オンラインスナップショットを取り，データの整合性を保つ
    - 整合性チェックに失敗したら，保存せずに異常終了とする
    - Macからpullする形で6時間ごとに遠隔コピーを取る
- スマホからも使用可能
- 難点はマスターパスワードを忘れると復号手段も無く詰むこと

### Forgejo

- 自己ホスト型Git
- GitHub以外のバージョン管理システムを試したかった
- 例によって，Tailscale ServeでHTTPS化して，運用．バックアップの仕組みも同様
- DBは別システム(Vaultwarden)で採用していたSQLiteを選んだ
- 付箋型アイデアグラフのアプリを自作して，実際にGitとして運用できるのを確認

## その後

- ここまでの設定をわずか数時間でClaudeがやってくれた
- とくにトラブルなく運用中
- おおむね試したいことや困りごとが解消されたので，他に面白そうなのがあれば試したい
